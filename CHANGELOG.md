# Changelog

## Unreleased — Filters, authoring panels, code preferences and classic Flash workflows

- Work protection: macOS Quit (including ⌘Q) now offers the same Save/Discard/Cancel protection as closing a document. Failed Open and cancelled or failed Save retain unsaved work and recovery files. Automatic formatting rolls back if saving fails and remains undoable after a successful save. Crash copies wait until the current recovered document is saved or closed, and unanswered recovery prompts survive quitting. Document-session and complete named-workspace state are tested foundations; their switcher and management controls still await NF2 design.

- Object Paste no longer inserts twice when keyboard and native paste events arrive out of order or with intervening pointer input. Each payload keeps its own paste mode and one Undo step.

- Lasso keeps the two-tone selection hatch visible after selecting artwork; selection still covers whole placements. The narrow Tools rail opens a group when its corner mark is clicked, without switching the active tool.

- Moving selections now preserve guide/object/grid/pixel snapping priority across all edges and centres. The main-menu coverage table now distinguishes working, context-dependent and unavailable commands. Grid settings now offer Dynamic (default) and Static modes. Dynamic adapts thin-line colour/opacity to the page background and retains coarser divisions when zoomed out; Static preserves the chosen colour and spacing. Mode changes preserve the manual colour and snapping step.

- Actions preserves diagnostic severity, codes, Unicode ranges and project-file locations; warnings use existing NF2 markers and counts. ⌘. applies a unique safe fix with one Undo. Shared compiler-token analysis improves scoped hints and multiline members. Exported handlers, classes and modules carry source maps used by Test Movie errors and trace output. Error-peek/fix selection and a connected pause/step debugger remain pending.

- Brush uses pen pressure for variable-width vector ink, with a macOS tablet-event bridge, a matching live draft and one Undo per stroke; ordinary mouse width is unchanged. Pen cancellation preserves the document. Physical tablet acceptance and pressure/tilt options remain pending. Gap-closing and partial-stroke geometry now preserve separate contours, fills, gradients and groups; their authoring controls still await NF2 design.

- Timeline: classic Orient/Snap controls, Paste motion special, editable Bézier motion paths (format 8), draggable a–z shape hints, and real mono/stereo sound waveforms computed in the background. Option-drag breaks a motion tangent; Option-click toggles corner/smooth. Shape hints support ⇧⌘H, ⌥⌘H and offstage removal. Selective paste materializes affected spans to preserve unticked animation; normal single-object curved motion stays editable.

- Selected raw shapes are easy to see on any artwork: the selection hatch is now two-tone (white and black lines) instead of a single grey line that disappeared on blue or light fills. NF2 design system updated to v2.2 (tool flyout groups, Commands, Brushes, Brush and Pencil tool panels, 15 new icons, timeline and field layout rules), with design answers for Paste motion special, classic tween Orient / Snap, motion path Bézier handles, shape hints and real sound waveforms.
- Drawing and docking previews: the Oval tool shows its live curved contour, including circles, arcs and inner radii; dragging a panel shows its actual contents before release, including an inactive tab, and retains its preview position and size when detached. Panels pulled from top/bottom docks immediately use a compact floating layout at normal text size instead of the full dock width.
- Selected tools remain active after creating shapes, paths or text, importing graphics and sampling colors. Repeated gestures use the same tool until it is explicitly changed; Space remains temporary pan.
- HTML5 publish size levels (`neoflash-export --size-level full|balanced|compact|shared`): Balanced ships WebAssembly as a separate streamed file instead of base64. Compact also leaves out the AIR, AS3 networking/system, text engine/Stage3D and AS3 media families that the project's scripts never name, plus every script-only module and the compiled prelude when a project has no scripts, and strips the WebAssembly code only those families reach. Shared publishes only the project and loads a runtime folder written once with `--shared-runtime`, refusing a mismatched build. `--size-estimate` reports files, on-disk and gzip size with a breakdown for every level. For a scriptless banner the package shrinks from 12.8 MB (4.1 MB gzip) at Full to 7.1 MB (2.1 MB gzip) at Compact and 20 KB (5 KB gzip) at Shared. Full stays the default. Editor Publish and publish-on-save now share persisted size/font options with a cancellable background estimate controller; the user-facing size selector still awaits R-032. Estimates include all generated files, and invalid Shared runtime directory URLs fail before writing output.
- Selection and Merge Drawing: clipped shape hatching to actual fills, strokes, holes and masks; prevented brush triangulation from becoming selectable fragments after nearby or crossing strokes; protected grouped Merge artwork from outside drawing; preserved gradient placement under affine edits. Group rejects selections spanning other keyframes with an explanation instead of crashing.
- Paint tools: Bucket and Ink apply the active gradient; Eyedropper clears the previous gradient when sampling a solid color. Properties RGB edits replace gradient paint, while alpha-only edits preserve its stop colors and geometry. Eraser now checks its whole disk and swept path, including masked and holed artwork.
- Timeline editing: layer copies relink copied motion guides; layer merge preserves guided poses, exposure and compatible frame sounds and refuses sound collisions or changed Stream spans without data loss. Play all scenes reaches later scenes with Loop playback off. File → Revert reloads saved `.fla` archives through the format-aware loader.
- Clarified authoring limits: pressure input, Bucket gap-closing controls, segment/partial-fill erasing, user-named workspace presets and multiple open document tabs remain unavailable in the interface.
