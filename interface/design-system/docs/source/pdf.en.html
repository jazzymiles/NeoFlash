In short

NeoFlash is a desktop vector-animation editor in the tradition of Macromedia / Adobe Flash: a stage, a timeline with layers and keyframes, nested symbols (movie clip, graphic, button), ActionScript-style scripting and publishing to HTML5 (Rust / WebAssembly), video, images and audio.

The design system NF2 keeps the mental model Flash animators already have and modernises everything around it: one primary action per screen, task-grouped controls, surfaces instead of borders, two themes on one set of tokens, accessible contrast and focus. Every element is a real Figma component bound to variables — no bitmaps.

1Overview and principles

The Figma file holds two independent versions. v1 is a faithful vector reconstruction of the shipped interface (NF1 components and tokens). v2 is the redesign with its own system (NF2). No variable, text style or component is shared, so changing one version never affects the other.

One primary pathEvery screen has one obvious primary action — Publish, Play, Save, Apply. The rest is secondary.
Group by taskTransport, onion skin, zoom and layer actions are grouped controls, not scattered rows.
Surfaces, not bordersDepth comes from background levels: app → panel → raised → field. Borders only separate.
SystematicOwn colour, spacing and radius variables, text styles and components; two themes on one collection.
AccessibleText contrast ≥ 4.5:1, 2 px focus ring, hit areas ≥ 32 px, tooltips with shortcuts.
Flash-literateLayer kinds, frame states, keyframe glyphs, symbol types, menus and shortcuts follow Flash.

2Foundations

Colour

All colours are variables of the collection NF2 · Tokens with two modes, Dark and Light. A theme is switched by setting the mode of a frame (in code: data-theme="light"); component structure never changes.

  • Surfaces stack bg/app → bg/panel → bg/raised → bg/field; bg/hover and bg/selected for interaction. bg/canvas is the pasteboard, bg/stage the document background (user content, same in both themes).
  • Accent is the only interactive colour: primary buttons, selection, active tool, toggles, focus.
  • Red is reserved for errors and destructive actions (plus the Flash conventions: playhead and frame labels). Breakpoints are orange, warnings amber, strings green, XML tags blue.

3Icons, cursors, states

Icons

Monochrome stroke icons on two grids: 16 px for the interface and 20 px for tools. Icons have no colour of their own — each instance is recoloured by token (secondary text by default, primary on hover, accent when active). The Icons page in Figma shows every icon with where it is used; unused icons are listed separately as candidates for cleanup.

{{GEN:icons}} {{GEN:img:docs/illustrations/icons-page-tools-section.png|Icons page — tools section with “Used in”}}

Cursors

39 cursors, 24 × 24, black glyph with a white outline so they read on any stage colour. The hotspot is stored in each component and must be used when implementing.

{{GEN:cursors}} {{GEN:img:docs/illustrations/icons-page-cursors-section.png|Cursors with hotspots}}

Elevation, focus and states

  • Floating panels and popovers: raised surface, radius 12, 1 px subtle border, shadow y 12 / blur 32 / 35 %. Dialogs: shadow y 16 / blur 48 / 45 % over a dimming overlay.
  • Focus: 2 px accent ring, 2 px outside the control, shown only for keyboard focus.
  • Hover: bg/hover; pressed / on uses the Selected variant; Disabled variants use disabled text and lose hover.
  • Tooltips: inverted surface, name + shortcut chip (“Selection  V”).

5Timeline

The timeline follows Flash semantics exactly, so Flash users recognise every state at a glance.

{{GEN:img:exports/interface/dark/png/timeline-states-legend.png|Timeline legend: layer types, column toggles, frame states}}

Geometry

  • 12 px per frame in Normal view; Tiny 6, Small 9, Medium 16, Large 22 px. Rows 28 px (Short: 18 px).
  • Ruler 32 px: seconds on top (at 24 fps), frame numbers and ticks below. Layer column 280 px.
  • Grid: every 5th frame shaded; per-frame lines are drawn over spans so filled frames stay countable.
  • Frame n starts at x = (n − 1) × 12; a span of k frames is k × 12 wide.

Columns: visibility (dot / red ✕), lock (dot / lock), outline (solid / outline-only layer colour). The pencil marks the current layer.

Frame states

{{GEN:timeline-states}}

Markers: keyframe ●, blank keyframe ○, span end ▯, property keyframe ◆, action keyframe “a”. Labels: red flag (label), green // (comment), ⚓ (anchor). The playhead shows the frame number on the frame row and the current time on the seconds row.

Frame view modes

The ⋯ menu of the timeline sets placement (bottom, top, left, right, floating) and the frame view: Tiny, Small, Normal, Medium, Large, Preview, Preview in context, Short, Tinted frames; plus seconds on the ruler and snapping the playhead to keyframes.

{{GEN:img:exports/panels/dark/png/timeline-frame-views.png|Timeline view menu and every frame view mode}}

Nesting and large projects

The breadcrumb shows the editing path (Scene ▸ symbol ▸ nested symbol); each item can go back up, its ▾ lists siblings, a long path collapses into “…”. The Symbols & scenes popover handles hundreds of symbols: search, scenes, matches (“3 of 248”), recent, browse by folder, keyboard hints. Button symbols get the four-frame timeline Up · Over · Down · Hit.

6Panels

Detached panels share one header (drag grip, up to three tabs, panel menu, collapse, close), the raised surface, radius 12 and a shadow. Bodies use 12 px padding and collapsible section headers. Every panel exists in Dark and Light; the Light versions are in exports/panels/light/.

7Code editor

Roboto Mono 13 px with line height 1.6. The gutter shows line numbers and markers: error, warning, breakpoint, execution arrow, folding. Errors also appear inline under the line with a quick fix, and on the overview ruler. Code hints, script tabs, a toolbox and a script navigator complete the Actions panel (see chapter 6).

Updating

  1. Change the design in Figma (v2 pages only; bind colours to NF2 tokens, text to NF2 styles).
  2. Start the receiver: python3 tools/receiver.py.
  3. In Figma Desktop run Plugins → Development → NeoFlash Export → Export.
  4. Rebuild: python3 tools/build-docs.py && tools/build-pdf.sh.
The Figma MCP server is limited to 200 calls a day, so exports always go through the local plugin.
