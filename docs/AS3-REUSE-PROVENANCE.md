# AS3 Rust geometry reuse experiment

The experiment adapts selected Vector3D, Matrix3D and Utils3D implementations into NeoFlash's existing Rust core. It does not embed Ruffle, AVM2, OpenFL, a second source compiler, or another rendering engine. Existing AS3 source compilation and the NeoFlash player remain in use. `web/geom3d.js` marshals arguments/results and exposes the native classes; all vector/matrix values, mutations and geometry arithmetic are in `neoflash-core/src/as3_geom.rs` and its WASM binding.

Pinned upstream: [Ruffle `07d3e430631333f80f754df01a968bdcd80d98c5`](https://github.com/ruffle-rs/ruffle/tree/07d3e430631333f80f754df01a968bdcd80d98c5). Ruffle permits MIT or Apache-2.0; this adaptation selects MIT. Exact source hashes and the member inventory are in [reuse-as3-inventory.json](../scripts/reuse-as3-inventory.json).

The exact Ruffle and OpenFL copyright/permission notices are retained in [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt), which accompanies exports.

The implemented partial profile adds 43 methods, nine properties, two constructors and three axis constants. One grouped Rust test covers this family. Final browser acceptance passed 39/39 checks and all 52 methods/properties; Advance moved the authored marker. The initial 37-check family also passed Restart. Execution evidence is recorded separately in the inventory. These are API entry counts, not language constructs or a Flash compatibility percentage. No existing geometry member was replaced. `examples/reuse-as3.nflash` is one ordinary authored project exercising every listed method/property, with Run, Advance and the standard export Restart. Actual browser results are recorded separately from implementation and scenario inventory.

Boundaries: finite inputs only; bounded arrays; decomposition/recomposition/interpolation/pointAt are explicit diagnostics; no native subclassing; no 3D display integration. Utils3D additionally requires complete xyz triples and finite non-zero homogeneous w. The example uses Rust-transformed x/y coordinates on the existing 2D display list. Strict sixteen-element raw input and non-finite diagnostics differ from some upstream edge behavior. These methods are partial support, not complete AS3 compatibility.

The earlier Royale/OpenFL source-to-JS experiment was stopped on user correction before browser acceptance. Its source/toolchain/probes remain only under ignored `target/`; they are not part of this implementation or its verified counts.
