# 0034 — Bounded AS2 runtime batches

Status: accepted for the authorized AS2-only delivery, 2026-10-28.

AS2 support grows by coherent subsystem packages over the owned Rust graph,
parser, broadcaster and linker. Reuse individual compatible algorithms and
contracts with pinned provenance. Browser adapters bind host facilities and
references; no complete legacy engine is embedded.

Sparse AS2 depth state is separate from ordinary display child indices. Runtime
clip duplication serializes a typed packet so ObjectRef identity has the same
canonical representation as other display bindings. Static/authored timeline
copying remains an explicit diagnostic until instance state can be copied safely.

AS2 XML adds an inert declaration/DOCTYPE and ID-map layer around the existing
parser, without DTD expansion or external entities. Browser fetch/navigation keeps
its ordinary security rules. System capabilities describe NeoFlash's browser
profile; they do not impersonate Flash or invent inaccessible OS controls.

Legacy operators are parsed only in AS2 and execute via shared Rust kernels.
In particular the `<>` token must not consume AS3 E4X XMLList delimiters. AS2
interfaces reuse the existing linker with explicit AS2 declaration restrictions.

One shared regression pass and representative HTML5 projects provide delivery
acceptance. Catalogue reviews name exact AS2 IDs and distinguish new code,
extended behavior, migrations and previously working code. Partial is a bounded
profile, not full historical conformance. See [the delivery report](../AS2-RUNTIME-HOUR.md).
