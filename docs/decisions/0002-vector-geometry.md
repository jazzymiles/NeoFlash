# 0002 — shared vector geometry and rendering

Status: accepted, 2026-10-26; performance architecture updated 2026-11-07.

The document stores renderer-independent path commands: move, line, quadratic/cubic Bézier and close. A path can contain multiple contours with either nonzero or even–odd fill. Paths and parametric primitives retain solid or gradient fill/stroke paints in document coordinates. Native GPU objects, editor cache keys and browser `Path2D` handles never enter the source file.

The Rust core validates commands, computes analytic curve bounds, performs bounded adaptive flattening and provides local-space winding/stroke hit tests. Authored keyframes interpolate compatible paths and the shape-tween engine resamples incompatible contours separately. Browser and native consumers use the same evaluated commands, fill rules and affine transforms.

Merge Drawing is a planar vector operation, not a raster approximation. Its broad phase uses conservative bounds and two-dimensional segment/ring indexes; only overlapping contour windows enter boolean work. Moving many compatible same-paint fill islands bakes their shared Stage transform once, partitions them below command and flattened-point budgets, and processes each bounded compound batch in one pass over the keyframe. Batches are accepted only when fill winding and element-level presentation are compatible; the compound is temporary, and disjoint source elements keep their IDs, names and order. Geometry failures roll the whole move back to the already-moved source elements and original selection IDs, so an optimization cannot consume artwork. Different paints retain their subtraction order; strokes, holes, scripts, accessibility, filters, alpha, blending and dormant paint settings keep their prior semantics.

The desktop Stage prepares a dual path fingerprint only for its evaluated editor scenes. Core runtime, export and HTML5 evaluation remain unchanged and pay no fingerprint scan. The fingerprint keys bounded local bounds and lyon tessellation caches; solid, unclipped authored paths additionally retain the final screen-space `Arc<Mesh>` by draw identity and exact geometry, transform, viewport, zoom, paint and outline state. A changed draw replaces its own slot rather than accumulating drag positions. Gradients, drafts, masks, blend captures and clipped geometry keep their established adaptive paths. Shape-selection hatches retain clipped meshes and translate them exactly during a pure move; a cold rebuild is tested to produce the same vertices, indices, colours, UVs and clip rectangles.

Brush input remains authored vector geometry. Pressure-aware spine simplification is bounded, and the round-brush self-overlap preflight uses an X sweep with indexed Y intervals instead of comparing every non-adjacent segment pair. The fallback envelope and resulting `PathCommand` sequence are unchanged. Finishing a gesture creates one Undo transaction; overlong drafts are rejected with an explanation rather than truncated.

The native renderer uses [lyon tessellation](https://docs.rs/lyon_tessellation/1.0.23/lyon_tessellation/) for concave/compound fills and strokes. The browser uses Canvas paths with the same commands, fill rules and stroke style. Tests cover contour holes, winding, curve extrema, transforms, point edits, bounded cache invalidation, masked/clipped fallbacks, exact selection-hatch translation, dense Brush envelopes and exported drawing/hit behavior.

The retained/locality design was checked against [VectorCraft at `4134158907ec38a0d06e786aa65c20aacd1ec5e7`](https://github.com/storytold/vectorcraft/tree/4134158907ec38a0d06e786aa65c20aacd1ec5e7), a permissively licensed Rust reference (MIT or Apache-2.0). NeoFlash adapts the architectural ideas of two-dimensional overlap preflight, bounded geometry work and retained renderer state to its own document, lyon pipeline and Merge Drawing semantics; no VectorCraft source was copied.

Current limits are explicit. Merge booleans operate on bounded flattened contours rather than preserving source Bézier segments. The editor does not yet have document-level structural sharing, dirty-region replay or a background geometry worker, so evaluation and ordered scene traversal still occur each frame. Brush output deliberately preserves the existing silhouette instead of switching to cubic curve fitting. These are future engine layers, not reasons to rasterize or silently simplify authored vectors.
