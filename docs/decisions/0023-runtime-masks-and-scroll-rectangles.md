# Timeline and runtime masks and scroll rectangles

Status: accepted for the bounded runtime profile, 2026-10-27.

## Clipping belongs to the display graph

Masks refer to live object identities, not instance names or authored placement paths. Runtime state owns mask assignment, single-owner reuse, copied scroll rectangles and cleanup. Each snapshot carries a shared clip table; draws refer to clip IDs instead of copying complete mask geometry for every descendant. Components inside one vector mask form a union, while a target's inherited clip chain forms an intersection.

Geometry masks use filled silhouettes, including transparent fills and compound holes. Paint color, opacity and strokes do not define uncached mask geometry. Sources are consumed and do not independently draw or receive input. Sources can contain nested symbols and animated/tweened authored timelines. Authored nested mask layers retain their own clipping before becoming an outer source.

Scripted soft masks use the existing `cacheAsBitmap` contract on both source and target. Authored and dynamic gradient fills preserve their opacity ramps; decoded PNG/bitmap alpha and mixed vector/bitmap containers preserve concatenated transforms and color alpha. Explicit `LayerProperties.mask_mode = "alpha"` in format 9 enables the same painted coverage for timeline masks. Missing `mask_mode` means Geometry, so old documents keep their appearance and version. A timeline alpha-mode selector still awaits the NF2 design answer (R-048); the engine and native preview accept saved alpha-mode documents.

A snapshot carries optional `RuntimeClip.alpha_components`; absence preserves geometric coverage and an empty array is an empty soft mask. Components retain nested clip dependencies. Shared Rust normalization unions source content before applying a common inner soft mask. Target layers composite before their mask; separate target layers retain independent groups. Inherited target masks are deferred, never applied again to an inner mask source. Native previews sample the shared prepared coverage and composite existing stage meshes; HTML5 uses the same clip/group graph with Canvas surfaces. Neither evaluation path executes scripts or sounds.

Text/video mask sources, fully scripted masked-source subtrees, overlapping script source subtrees and scroll rectangles inside script sources still diagnose. Bitmap masks require explicit source/target caching; disabling an explicit cache that would invalidate the assigned source fails atomically. Removing the last implicit filter cache without explicit caching remains a limitation. AS2 String target paths and ordinary catch handling for raw host errors remain outside this profile. Active mask/scroll entries are capped at 256, inherited chains at 32 and authored source geometry at 100,000 reserved commands alongside the dynamic Graphics budget. Native previews use bounded four-million-pixel rasters, cached immutable resource decoding and bounded per-frame coverage work; exact Flash raster/filter fidelity is not claimed.

Scroll rectangles are copied on write and read. The first cross-dialect profile accepts integral finite x/y/width/height with nonnegative sizes, and applies changes immediately. Fractional and historical deferred-rounding behavior is explicitly outside this profile. A base transform stays unchanged; content coordinates include the negative scroll offset. Viewport geometry uses the base transform and intersects ancestor clips, so pixels, coordinate conversion and bounds share the same model.

AS3/JavaScript absence is null. The AS2 compiler maps an absent native scrollRect to undefined without changing local variables or ordinary object fields. AS2 setMask implements the observed Boolean-success behavior for direct object/null assignment; the old documentation's Void signature and unsupported String target paths remain distinguished.

## One renderer and one interaction boundary

The browser composites mixed-rule mask components using shared Path2D geometry and two reusable bounded surfaces, then intersects nested clips. Pointer routing tests each clip union with the same paths. Semantic targets use visible bounds from the already clipped render, with bounded tiled alpha readback only for leaves that contribute to authored semantics. Fully clipped targets and mask holes cannot produce independent ghost buttons. Raster antialiasing and full accessibility conformance remain separate evidence.

The clipped-scene workflow combines five linked cards in a scrolling viewport, a linked panel clipped by a compound/circular mask and its parent viewport, and AS2 setMask/scrollRect. One advancement moves the views/mask, another removes masks, and Restart recreates all instances. The same family covers AS2/AS3 cached authored gradient/PNG sources, tweened masks and Restart. Core timeline/runtime mask tests cover old-document defaults, save/reopen, nested coverage and independent target layers; editor tests cover final native pixels, resource replacement and one Undo. Real exported Canvas pixel probes verify transparent/partial/opaque PNG pixels, gradients, compound holes, nested sources and targets, shared-mask layer overlap, motion and Restart. Native Dark/Light captures exercise the actual stage; these checks do not establish every Flash display/filter combination.
