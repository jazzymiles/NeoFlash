# AS2 legacy syntax and target globals

This batch adds eleven deprecated source operators: `add`, `eq`, `ne`, `lt`, `le`, `gt`, `ge`, `and`, `or`, `not`, and `<>`. The Rust frontend parses their AS2 precedence and rejects the infix forms in AS3. UTF-16 concatenation/comparison, Boolean operations and numeric inequality execute in the shared Rust string service. The browser bridge only evaluates/coerces operands and transports code units or numbers. Legacy `and`/`or` evaluate both operand expressions and return Boolean values; modern `&&`/`||` retain their existing behavior.

Seven global entry points connect to the owned display graph: `getProperty`, `setProperty`, `targetPath`, `duplicateMovieClip`, `removeMovieClip`, `startDrag`, and `stopDrag`. Rust maps numeric property indices and resolves display paths. The wrappers share existing display mutations and the AS2 method bridge. Object arguments and absolute `_root`/`_level0`/slash paths work. Relative string paths currently resolve from the publication root, not the caller MovieClip. Only runtime-created clips can be duplicated; authored/linked timeline duplication diagnoses. Unsupported numeric property slots diagnose, and read-only assignments keep the underlying display diagnostics.

The existing `parseInt` algorithm was moved from JavaScript into Rust, preserving the existing profile, conversion order and automatic/specified radix differences. This is one migration, not a new API. It retains NeoFlash's previous signed-octal handling; complete historical player-version coercion parity is not claimed. The transport keeps NaN/infinity/signed zero as strings. Inputs retain the shared one-million UTF-16-unit and 32 MiB transport limits.

## Reuse

Individual opcode contracts and the integer parser were adapted after reading Ruffle at pinned revision [`89a7049965f3090e706265670df309a5128233ac`](https://github.com/ruffle-rs/ruffle/tree/89a7049965f3090e706265670df309a5128233ac): `core/src/avm1/activation.rs` (`action_and`, `action_or`, `action_equals`, `action_string_add`, string comparison) and `core/src/avm1/globals.rs` (`parse_int_internal`). The AS2 reference operator descriptions are preserved in the [Open Flash documentation mirror](https://open-flash.github.io/mirrors/as2-language-reference/operators.html). We select Ruffle's MIT license; the existing exact notice in `THIRD_PARTY_NOTICES.txt` ships with exports. No VM, compiler, renderer or third-party runtime is embedded. Source downloads remain under ignored `target/`.

## Evidence and accounting

`examples/as2-legacy-batch.nflash` is one ordinary authored AS2 project, compiled/exported normally and executed in the browser with real Rust WASM. It passed **24/24** grouped assertions and passed again after Restart. These include the operator family, eager legacy Boolean evaluation, precedence, UTF-16, integer parsing/alias, numeric properties, target paths, duplicate/remove globals and bounded drag start/stop. Its final four checks also exercise previously existing comma, void, delete and int behavior. These existing declarations are catalogue corrections, not new syntax.

The existing `reused_as2_string_family_scenario` native test was extended and passed; no new test case was created for this package. This is useful partial support, not a claim of SWF4 numeric Boolean values, arbitrary AVM coercion, all parser combinations or original-Flash differential conformance. The shared delivery report records regression results and remaining limitations.
