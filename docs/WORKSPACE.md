# Workspace

NeoFlash uses a compact classic workspace. **Window → Appearance → Light / Dark** or **Edit → Preferences… → General → Theme** (previewed immediately, kept with Save) changes both ordinary controls and manually painted timeline/stage overlays. Authored colors, fonts, scripts and document history are independent of the theme.

The [NF2 design system](DESIGN-SYSTEM.md) defines the visual and interaction standard, implemented in `crates/neoflash-ui` from the Figma export in `interface/design-system`. It is separate from the implemented workflows described here.

## Panels

Window controls Timeline, Tools, Library, Properties, Actions, Accessibility, Output, Align, Transform, Color, Brushes, Ease, Scene and Motion editor. Align, Transform, Color, Brushes, Ease, Scene and Motion editor start hidden; Ease also opens from the Timeline Ease button and Frame menu ▸ Ease…, Scene with ⇧F2. Panels and dialogs that do not work yet open as read-only previews from their menu items and **Window → Planned panels**. A hidden panel can be shown again from the same menu. **F9** reveals Actions and focuses its editor even while typing in another field. Selecting a frame first makes it the Actions target; the timeline's context menu and **Actions · F9** button also open that frame directly. The header identifies the current symbol and frame. Opening Actions pauses preview playback.

All panels support **Window → Detach / Dock** and header dragging between the main window and native floating windows. Drag a tab to move one panel; drag the empty internal header/grip to move its entire tab group. Drop on any of the four highlighted edges, to a tab group, or to a group's split target. Top/bottom areas split horizontally; left/right areas split vertically. Resize areas using their visible boundary grip strips and groups at their dividers; the top/bottom grips change Timeline height. Chosen sizes persist separately from project content. The panel drag preview shows its actual contents while the button is held, including when dragging an inactive tab, and follows the pointer over the Stage and between dock targets inside NeoFlash windows; outside their bounds it is not drawn. When pulled from a top/bottom dock, a panel immediately uses its floating layout and compact size; previously saved dock-wide geometry is capped at the standard floating size. Text and controls keep their normal scale. Detaching keeps that preview position and size, subject to screen recovery; Escape leaves the original active tab and docking unchanged. Drop outside the targets to open a native floating window. The default right side shows Library above Properties. Floating windows can contain tab groups and horizontal/vertical splits, with drop targets on all four sides. The macOS title bar moves the whole window; a panel tab or internal header performs docking.

Actions has a sidebar (toggle **Show toolbox sidebar**; hidden automatically when the panel is narrower than 640 points). The toolbox lists only ActionScript declarations that NeoFlash implements or partially implements, grouped as Top level, Language elements, Project classes and packages; hovering a class shows its support level, double-clicking an entry inserts it (AS3 classes and static members also get their `import`). The Script navigator lists the current script, the main timeline's scripts, symbol definitions and project files; clicking one enters its timeline, frame and object. Code hints open after `.`, with ⌃Space or **Show code hint**; they resolve `this`, `name:Type` declarations, named stage instances and class names (static members), and never edit text until a hint is chosen. Auto-format only re-indents. Scripts are checked silently 0.6 s after typing stops.

The compact **⋯** header menu contains Edit and docking commands, without a separate toolbar row. **Dock** returns a floating panel to the main window. Closing a floating window hides its panels and retains their layout so Window or F9 can reopen them. Escape cancels a panel drag. Floating panels follow the active document; each open document retains its own selection, playhead, script state and Undo. Actions retains the text cursor when moved between its dock and native window; native text shortcuts and the detached Edit menu address that text field.

**Window → Workspace** and the top-bar workspace selector list built-in layouts and **My workspaces**. **Save workspace** creates a named layout; **Replace** explicitly overwrites an existing name, while Rename rejects collisions. **Update** stores the current arrangement and **Reset** restores the selected saved layout. Up to 32 presets retain panel visibility, active tabs, dock sizes and floating/native window layouts. Names are 1–64 characters and cannot use a built-in name. Deleting the active preset keeps its arrangement and shows **Unsaved layout**; Reset stays disabled until a saved layout is selected or the arrangement is saved. These operations preserve documents, selection, Undo and unfinished edits. Tool preferences are global and independent of layout presets.

Layout/theme preferences are saved separately by the application; saving a project does not include machine-specific window positions. **Edit → Preferences…** (`⌘U`) and **Edit → Keyboard shortcuts…** (`⌥⇧⌘K`) edit persistent workspace settings across General (theme with live preview, UI scale, startup document / **File → Open recent**, undo levels, periodic autosave to `<app_support>/Recovery` with launch crash-recovery prompt, tooltip shortcuts and Shift-select), Code editor (font family/size/line height, line numbers, word wrap, auto-close brackets, code hints + delay, tab size, format on save and current-line highlight), Timeline (span-based selection, frame view/row height, seconds, snap playhead, onion range and linear opacity falloff, auto keyframe on transform, default ease and tween type on drag), Drawing (pen preview, precise cursors, connect lines, smooth curves, line/shape recognition, click accuracy, snap tolerance and snap to pixels), Text (font/size and font substitution warning), Clipboard (default paste and SVG paste as editable paths vs bitmap), Shortcuts (98-command registry driving menu/tool labels and dispatch, custom sets, search/filter, key recording, conflict detection, reset and HTML export) and Publish (default output folder, warnings as errors and publish on save). On macOS, disconnected-display recovery uses the usable areas of all connected screens and moves inaccessible panel title bars back into reach.

**New** and **Open** insert a document tab after the active tab. Opening an already open file or imported source activates its tab without reloading or replacing edits. Imported sources keep a separate session identity: saving the converted document chooses its own destination. The tab strip and **Window** document list show unsaved state and offer Next/Previous document (⌃⇥ / ⌃⇧⇥), Close (⌘W), Close other documents and Close all (⌥⌘W). Each document retains independent Undo, selection, views and recovery. Closing the last tab leaves **No document open**, with New and Open available and document commands disabled.

Close, Close all and Quit activate dirty documents in tab order for Save/Discard/Cancel. Cancel and failed Save stop on the prompted document. Discard decisions take effect only after the entire sequence is approved, so a later Cancel preserves earlier unsaved content and recovery copies. New/Open, cancelled file pickers and failed loads preserve existing tabs. Failed Save rolls back automatic formatting; successful formatting is one Undo step. Each crash copy restores into its own tab; if its original path is already open, recovery creates an unnamed independent copy. Unanswered recovery candidates survive Quit. **File → Revert** reloads the saved document, including saved `.fla` archives. Ordinary Open does not reload an existing tab, and there is no automatic external-change reload prompt.

Workspaces contain panel layouts, not the document list or tab order for the next launch. On launch still chooses New document, Example or Last document; recovery is offered separately. Documents share one main window, selected tool and workspace. Arbitrary recursive main-window splits and Duplicate window remain unavailable. Native menus, VoiceOver, IME and mixed-DPI display relocation need broader platform acceptance.

Notifications appear above the canvas bottom, or above the status bar when the canvas is hidden. Up to three stack with the newest at the bottom. Repeats show a count and restart their timer; hover pauses expiry. Info/Success last 4 seconds, Warning 6 seconds, and Error remains until dismissed or its action is used. New notifications wait while a modal is open and never take focus. Partial-stroke refusals use Warning; failed Save uses Error with **Show**. Every notification is retained in its document’s Output, and Show reveals the diagnostic in the active document even after switching tabs. Output lasts for the editor session, not as a log on disk. Ordinary Open, successful Save, import and export retain their existing status/Output or dialog feedback.

## Timeline and compact windows

**Play preview / Enter** advances independent nested MovieClips even when the edited timeline contains one frame. **Pause** holds the displayed pose and resumes from the same nested clocks. **Rewind**, scrubbing, symbol navigation and document edits reset that transient state. Mask-aware picking follows the displayed pose. Preview never runs frame/object scripts; use **Test Movie** for scripted behavior. **Loop playback** (Timeline and Control menu) off stops on the last frame of the current scene, or the final scene when **Control → Play all scenes** is enabled. Play all scenes advances through every scene with looping either on or off. Preview plays timeline sounds through the Mac's default output (**Control → Mute sounds**, ⌥⌘M); scrubbing is silent.

Layer names and frame cells share one vertical scroll body, with a fixed ruler. Frames scroll horizontally within that body. Tools and Library scroll vertically when space is limited. Properties use aligned label/value rows, and onion controls wrap. Panel controls share a compact system font and stable heights. The Library preview stays above the scrolling browser. Tween arrows have a fixed six-point arrowhead clipped to their own row, independent of their span length. Icons use vector geometry instead of relying on installed symbol glyphs.

Layer names use compact left-aligned text, with row dividers through the name and property columns. Drag the vertical divider beside the layer columns to change their width; the horizontal resize cursor marks the grip. The width is a workspace preference. Double-click a name or choose **Rename layer** in its context menu. Enter or leaving the field commits a nonempty name as one Undo step; Escape cancels. **Frame zoom**, − / + and **Fit** change frame-cell width with adaptive ruler labels and keep the selected frame in view. They do not change authored frames, FPS or duration.

Scrollbars occupy separate strips outside the frame cells. Held content and blank-key intervals extend visibly to the next key or symbol end; the **End** marker separates actual frames from unused space. A key drag previews its destination and scrolls at the horizontal edge. Occupied destinations are refused. Drag a layer name to reorder layers; an insertion line marks the destination. Folders carry their descendants and masks carry their linked layers. Relationships are preserved; dragging does not change folder membership. Release outside the rows or press Escape to cancel. A completed move is one Undo step. Select frame ranges across layers to copy, cut, paste, move, clear, insert or remove time, and drag a layer's end handle (or type a number) to set its length; each is one Undo step. Active onion skin is identified in the stage header because neighbouring-frame ghosts can appear over an otherwise blank frame.

The minimum main window is 1024 × 720 logical points. Rendering and interaction regressions cover this size and larger windows, both themes, long libraries, many layers and long spans. See [the verification record](VERIFICATION.md) for the separately observed native checks and their limits.

## Tweens, guides, scenes and sound

The Timeline controls, the frame menu and **Insert** create three kinds of tween on the span under the playhead (one Undo each; the same button removes it):

- **Classic tween** interpolates the objects of two keyframes. Its ease is set in Properties or the **Ease** panel (presets, draggable Bézier handles, overshooting curves, Flash acceleration; Apply is one Undo step).
- **Shape tween** (green span) morphs rectangles, ovals and paths between two keyframes, also when their contours differ; fills, strokes and compatible gradients blend. Symbols, text and bitmaps on the layer hold still, and a keyframe without shapes gets an explanation. Shape hints are not available yet.
- **Motion tween** (blue span) animates one symbol instance or text block. Moving, scaling, rotating or recolouring it inside the span adds a ◆ property keyframe that keys only what changed; F6 keys every property. While the playhead is in the span, the selected instance shows its path with a dot per frame; drag a ◆ point to move that key. **Window → Motion editor** lists each property track with its keys (add/remove a key at the playhead, type values, drag a key's value); Properties shows the span's ease, rotation turns and direction, Orient to path and path box (Orient to path is saved but does not turn a motion tween yet). Copy motion / Paste motion (frame menu) repeat a tween on another object. Per-property eases, Bézier path editing and Paste motion special are not available yet.

**Add motion guide** (Timeline, Insert, layer menu) inserts "Guide: <layer>" above the layer; classic tweens on the guided layer follow the guide's first stroke, optionally turning with it (Orient to path is stored per tween; the classic Tween section has no control for it yet). Frame commands include Clear keyframe (⇧F6), Convert to keyframes / blank keyframes, Reverse frames and Synchronise symbols. **Edit multiple frames** shows every keyframe in the onion range and moves the selection on all of them.

The Scene select lists the document's scenes and adds new ones (also **Insert → Scene**); **Window → Scene** (⇧F2) finds, adds, duplicates, deletes, renames (double-click) and reorders them. Scenes play one after another in HTML5.

The Timeline **Sound** button attaches a library sound or **Import sound…** (MP3/WAV) to the span's keyframe; layers holding only sounds show as Sound layers (their waveform drawing is decorative). Properties ▸ Sound sets Effect, Sync (Event, Start, Stop, Stream), Repeat or Loop, shows file information and plays the sound once. Edit envelope and Sound properties are not available yet.

**Frame view** (⋯ in the Timeline) offers Short rows, Snap playhead to keyframes (⇧ suspends it), Preview and Preview in context (keyframe thumbnails in taller rows) and the Timeline's placement on any dock edge; these are saved with the workspace. Try `examples/timeline-tweens.nflash` and `examples/timeline-sound.nflash`.

## Creating symbols

**F8 / Convert to Symbol** offers a name, Movie Clip / Graphic / Button type and nine registration points. Conversion preserves the artwork's placement and commits as one Undo step. Multiple objects must form a contiguous stack on one layer so grouping does not reorder unrelated artwork. **Insert → New Symbol / ⌘F8** creates an empty library symbol and opens it. Movie Clips and Graphics start with one frame; Buttons start with four states, **Up / Over / Down / Hit**. The Up artwork holds until a new state key is added. Hit artwork defines input geometry and is not painted in HTML5. Add button actions to its instance on the parent timeline or its linked class; state frames are for artwork. Movie Clips and Buttons can export a runtime identifier and bind an existing class; AS3 bases are MovieClip and SimpleButton respectively. Empty `new SimpleButton()` and assignment of arbitrary state display objects remain unsupported. Graphic playback offers Loop, Play once and Single frame, with a separate First frame per placement. Library Properties changes the symbol type for all instances and refuses incompatible class linkage without deleting code. 9-slice guides and legacy SWF library sharing are not implemented.


The compact FPS and duration fields are linked. Editing either retains every frame; duration sets the nearest integer FPS (1–1000). Numeric property controls accept click-to-type or drag-to-scrub, Enter/blur to apply and Escape to cancel.

## Layer roles and operations

Right-click a layer for visibility/locking, insert/delete/rename, copy/cut/paste/duplicate, merge, symbol conversion and folder operations. A folder groups its descendants; hidden or locked folders affect them. Layer ▸ More ▸ Folder and mask… selects a parent folder or mask source; layer Properties… opens the NF2 Layer properties preview. Merge with Next Layer preserves exposure and guided animation, sampling tweened spans into keys when necessary. It retains compatible frame sounds and refuses a merge that would combine two sounds on one key or change a Stream sound’s span; the document remains unchanged on refusal. Copying or duplicating a guide together with its guided layers links the copies to the copied guide. Layer copy/paste currently stays within the open document.

**Mask** turns a vector layer into a clipping source and initially links the next normal layer. Other normal layers can select that mask in Properties. Filled rectangles, ellipses, paths and vector-only symbols clip artwork on the stage and in HTML5. **Show Masking** switches between the clipped result and editable source shapes. Text/bitmap mask sources and masks inside mask-source symbols are explicitly rejected; convert these sources to vector artwork first.

Click a layer’s colored square to switch between normal artwork and outlines. Right-click the square or layer and choose **Outline color…** to set its RGB color; Apply creates one Undo step and Cancel leaves the document unchanged. Folder outlines include their descendants. Outline display applies to the currently edited symbol and its layer folders; a nested symbol’s saved outline preferences do not override its parent’s artwork. Play preview shows original fills and strokes, as does HTML5.

**Guide** layers remain visible/editable in the authoring stage and are omitted from published output. A guide that a normal layer is linked to is a motion guide (see above); otherwise it is a visual guide. **Show Others Transparent** uses outline display for surrounding layers without changing their published opacity.

## Library and graphic import

Library shows a fitted first-frame preview above its searchable tree. Search matches symbol names, folders, linkage and class names. Sort by Name, Type or Linkage, with reversible order. New Folder and context-menu Organize controls create, rename and move folders/symbols. Empty folders and paths are document data; view filtering and collapsed state are workspace-only. Resource files remain a separate section.

Drag SVG, PNG or JPEG files onto the stage, or choose **File → Import graphics to Stage**. Multiple files create reusable symbols in the selected library folder and one Undo entry. Repeated identical resources are reused. SVG solid fills/strokes become editable vector paths; text uses installed fonts and becomes outlines. Gradients, embedded images, clipping and effects use a rendered image with the original SVG retained, with an explicit import message. Scripts, animation, embedded HTML and external file references are rejected with an explanation. Stored SVG/PNG/JPEG resources can also be dragged onto the Stage or placed using **Place on Stage**. Drag a Library symbol onto the Stage or use **Place** to create an instance. The Library’s **Import graphics…** button imports and places files; **Resource files → Add resource files…** only stores resources.

Imported graphics are fitted within the page around the drop point or visible view center. If the selected layer is a folder, guide, mask, locked, hidden or outlined, import creates a visible normal **Imported graphics** layer. Placement selects the new objects and stops playback. Native Finder drags use the current desktop pointer, including when the window system does not send ordinary pointer movement events.

Try `examples/authoring-workspace.nflash` and drag `examples/authoring-badge.svg` onto its stage. Document format 4 and later preserve layer roles and library folders; older documents remain readable.

## Drawing and color

Tools provide separate fill/stroke colors, alpha percentages and stroke width. New rectangles, ellipses, pen and pencil paths use these settings. Properties edit the selected artwork independently. RGB and alpha are stored separately, so making a paint transparent preserves its RGB color. A continuous property edit is one Undo step.


## Tools and Modify

In the narrow Tools rail, click a group’s corner mark, right-click, hold the button or press → while it has focus to open its flyout; clicking the button body selects its remembered tool.

The two-column Tools panel adds Line (N), Brush (B), Paint Bucket (K), Ink Bottle (S), Eyedropper (I), Eraser (E), Lasso (L), Hand (H), Zoom (Z/M) and Gradient Transform (F). The selected tool stays active after drawing, inserting text, importing graphics and sampling colors. Space temporarily pans without replacing it. The Oval tool previews its curved outline, arcs and inner radii; ⇧ constrains a circle and ⌥ draws from the centre. Completed drawing gestures form one Undo step. **Customize tools** edits a draft with Add/Remove, drag reorder and Restore default; Cancel/Escape discards it and OK stores the tool layout globally, independently of named workspaces.

**Window → Brushes** offers Round, Flat and Chisel presets. Brush properties provide eight tip shapes, Size 1–200 px in document units, smoothing, **Pressure controls size** and gradient **Lock fill**. The cursor follows zoom; ⌥⌘-drag resizes the brush. With pressure enabled, pen pressure scales width from 10% to 100% of Size; ordinary mouse input remains constant. macOS tablet-point events and pressure-bearing touch feed the same transient draft and saved vector outline. Pen-up retains the last contact width; cancellation leaves no artwork. Pencil has independent **Straighten**, **Smooth** and **Ink** modes, with per-tool smoothing based on Drawing preferences. Paint modes beyond Paint normal, tilt, custom/artistic/pattern presets and Pencil advanced stroke controls remain unavailable. Physical tablet-driver acceptance remains pending; Pencil uses the existing draft overlay rather than a predictive smoothing preview.

Bucket fills closed vectors and Ink Bottle applies strokes using the active solid or gradient paint. Eyedropper samples solid RGBA and replaces that drawing well’s gradient. Properties → Tool and Tools options expose Bucket **Gap size**: Don’t close gaps, Small (6 screen px), Medium (14) and Large (28). Each contour closes independently; bitmap flood fill remains unsupported. Gradient Transform adjusts an existing fill’s center, scale and rotation; radial focal handles remain unavailable.

Eraser Whole modes remove objects, fills or strokes touched by the disk and swept path, respecting vector holes, masks and locked layers. **Cut strokes** approximates touched curves while preserving fills, gradients and groups. Masked targets or combined fill/stroke effects refuse the entire gesture without an Undo entry, with a Warning notification and status/Output explanation. Guided/oriented clipping preserves the existing key pose; automatic guided-key insertion is refused if it would move artwork. Partial-fill erasing remains unavailable. Lasso selects whole placements by contact or enclosure of their bounds and retains selection hatching; it does not cut a partial fill.

**Merge Drawing** separates editable fills and strokes; real crossings can split them, while internal brush triangles and nearby nonintersecting lines do not create selectable fragments. Selection hatching follows the selected fill/stroke silhouette and masks, leaving holes and empty bounds corners clear. Moving Merge artwork preserves its gradient placement. Object Drawing keeps new shapes independent.

**Modify** offers grouping, safe static-symbol Break Apart, arranging, transforms and Align. Authoring groups preserve runtime identities and scripts; grouped artwork moves as one unit in alignment and spacing. Groups protect their Merge artwork from cuts or coalescing with drawing outside the group. Groups are currently nonnested and require a contiguous stack on one editable layer in the current keyframe; a selection containing objects from other frames produces an explanation instead of grouping. Break Apart rejects animated, scripted or class-bound content rather than losing its behavior.

**Modify → Bitmap → Trace bitmap** converts one selected bitmap (either a direct bitmap placement or a static 1-frame Graphic symbol instance created when importing or placing an image onto the Stage) into editable coloured vector paths. Colour, Greyscale and Black and white modes offer Limited/Full/Automatic palettes, seven presets, Colours, Paths, Corners, Noise, Abutting/Overlapping, fill/stroke output, stroke width, Snap curves to lines and Ignore white. A cancellable background preview shows bitmap and vectors side by side; Trace processes the full image. Cancel leaves artwork unchanged. Success preserves placement and the selected tool, groups multicolour paths and creates one Undo step; a single-colour result preserves holes and islands in one compound path. Source resources remain in the Library. Unsupported effects and size limits produce an explanation in the open dialog; see [tracing limits](COMPATIBILITY.md#native-timeline-authoring). The separate Bitmap properties editor remains unavailable.

**Align** provides six alignments, six position distributions, equal gaps, exact horizontal/vertical gaps (including negative overlap), matching dimensions and To Stage. **Transform** provides compact X/Y/W/H, linked scaling, rotation, skew, flip and reset. **Color** edits selection or drawing defaults with independent fill/stroke RGB and alpha. In Color and Properties, changing gradient RGB through a solid-color field replaces it with solid paint; alpha-only edits preserve the gradient geometry and stop colors and set the stops’ alpha. Properties drawing defaults use the same rule.

## Rulers, guides and grid

Rulers run along the top and left of the canvas in pixels, points, inches, centimetres or millimetres; drag their corner to move the zero point and double-click it to reset. Drag out of a ruler to add a guide; drag a guide to move it, back onto a ruler to delete it, or select it and press Delete. Guides belong to the scene or symbol being edited, are saved with the document (format 6) and are never published. The grid overlays the stage below or over artwork. Moves, transform handles, rectangles, ovals, lines, pen anchors and path points snap to guides and the grid with the chosen accuracy; a ring marks the snapping point. **View → Rulers / Grid / Guides**, the zoom control toggles, shortcuts (⌥⇧⌘R, ⌘;, ⇧⌘;, ⌥⌘;, ⌘', ⇧⌘', ⌥⌘G) and the **Rulers, guides & grid** popover (⚙ in the zoom control) change the same settings; **Save as default** keeps them for later sessions. Details: [NF2-RULERS-GUIDES-GRID.md](NF2-RULERS-GUIDES-GRID.md).

## Shared control system

Native chrome uses NF2 tokens and components from `crates/neoflash-ui` (Inter and Roboto Mono are bundled). The window follows the NF2 layout: a 48-point top bar with menus, project title, Test Movie and Publish; a 56-point tools rail; a 320-point inspector with Properties over Library; one full-width bottom dock with Timeline · Actions · Output · Accessibility tabs; a 24-point status bar with shortcut hints. Controls are 32 points, rows 28, panel tabs 36 and dock tabs 40. Breadcrumb, stage size and the zoom control float over the canvas. Dark is the default theme. Layouts saved by earlier builds are replaced once by this default. Window commands group detach/dock and appearance actions into submenus. Narrow timelines expose onion settings in a dedicated menu; Tools keeps paint and options fixed while its tool list scrolls. Properties follows document/frame/object context with an explicit Tool mode. Multiple-selection paint edits expose Mixed values and apply only the chosen field. Fresh compact workspaces tab Library and Properties together; resizing does not replace saved layouts.

Brush and Pencil properties currently use the larger shared NF2 type header; the approved compact header requires a shared component variant. Exact header-size fidelity is not yet provided.

When Library is too short for its inline preview, a compact Preview action opens the same preview in a popup while preserving list space and bottom commands. Enlarging the panel restores the inline preview preference and height. Focused scrollbars support arrow keys, Page Up/Down and Home/End, with a visible focus outline in either theme.

An intermittent Stage repaint issue remains open: artwork can briefly appear absent after changing the theme or opening a Library preview, then return on a later redraw. No authored content loss was observed.

Every panel can be closed the way it was opened: Window-menu rows toggle panels both ways, a tab's menu offers Hide, planned previews close from their header ✕, window dot or (popovers) a click outside, and detached panels close with the macOS window button. The in-window floating-panel fallback, used only by backends without native windows, does not react to its header ✕ in headless tests; macOS uses native windows and is not affected.
