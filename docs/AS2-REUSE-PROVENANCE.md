# AS2 Rust String reuse experiment

This bounded experiment adapts individual Rust implementations into NeoFlash's own core. It does not embed the Ruffle engine, its renderer or UI, or the Rascal compiler. NeoFlash's existing Rust ActionScript frontend and document/runtime model remain in use.

The reused source is [Ruffle](https://github.com/ruffle-rs/ruffle) at commit [`89a7049965f3090e706265670df309a5128233ac`](https://github.com/ruffle-rs/ruffle/tree/89a7049965f3090e706265670df309a5128233ac), the v0.7.1 revision. Upstream offers MIT or Apache-2.0; this adaptation selects MIT. The exact MIT notice is retained in [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt) and included by the HTML5 exporter.

The owned implementation is `crates/neoflash-core/src/as2_strings.rs`. `crates/neoflash-web/src/as2_strings.rs` only exposes a bounded JSON transport. Strings use UTF-16 code-unit arrays, so slicing, indexing, splitting and casing preserve lone surrogates. Numeric transport uses strings for NaN, infinities and negative zero.

`web/as2-strings.js` marshals values through a per-publication injected service. It retains observable input conversion order but contains no duplicate String algorithms. `fromCharCode` crosses WASM once per converted argument to stop before coercing values after a NUL; this prioritizes correct observable behavior over throughput for large argument lists. The old AS2 algorithm branches were removed from `actionscript/strings.js`; AS3 retains its existing separate behavior. A missing Rust runtime gives an actionable re-export diagnostic.

The count is **14 existing String members moved to Rust, 10 newly available globals, and no new language constructs**. The members are `charAt`, `charCodeAt`, `concat`, `fromCharCode`, `indexOf`, `lastIndexOf`, `slice`, `split`, `substr`, `substring`, `toLowerCase`, `toUpperCase`, `toString`, `valueOf`, `escape`, `unescape`, `chr`, `ord`, `length`, `substring`, `mbchr`, `mbord`, `mblength` and `mbsubstring`. Historical casing improves two existing members and is not counted as two additional APIs. The eight legacy globals are eight separately declared API names backed by four shared algorithms; these are not described as eight independent algorithms. User-defined aliases are not counted again. Other upstream APIs are not counted as supported.

`examples/reuse-as2.nflash` contains one authored text-processing scenario with twenty-seven checks, a visible result, a rerun button and a JSON trace. The checks exercise all twenty-four members plus UTF-16 preservation, a combined pipeline and an alias. The grouped native core test covers the same family and boundary behavior; the existing emitted-code String fixture uses actual WASM and adds new codec, historical-case, alias and shadowing checks. Browser acceptance evidence is recorded in the experiment's shared verification report; compiling this module alone is not browser verification.

Remaining boundaries are boxed AS2 String objects, method extraction/prototype augmentation, complete AVM coercion, SWF5-specific defaults, URL codec lone surrogates and malformed decoded UTF-8. UTF-16 strings and output are bounded to one million code units/items; input transport is bounded to 32 MiB. These counts describe this experiment, not complete AS2 or Flash compatibility.
