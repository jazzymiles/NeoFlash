# Rust AS3 String and text codecs

This family adapts individual algorithms into NeoFlash's existing Rust core and uses the existing compiler and HTML5 exporter. It adds no engine, compiler, regex backend or Cargo dependency. Browser code only performs value conversion, callback invocation and UTF-16/JSON transport. Existing RegExp dispatch retains its separately documented backend.

Pinned upstream: [Ruffle `89a7049965f3090e706265670df309a5128233ac`](https://github.com/ruffle-rs/ruffle/tree/89a7049965f3090e706265670df309a5128233ac), MIT selected from MIT OR Apache-2.0. The retained [MIT notice](../THIRD_PARTY_NOTICES.txt) also accompanies HTML5 exports. Adapted portions remain attributed.

Implemented files are `crates/neoflash-core/src/as3_strings.rs`, the small WASM binding in `crates/neoflash-web/src/as3_strings.rs`, and the transport in `web/as3-strings.js`. The old primitive AS3 algorithms were removed from the compiler's `strings.js` helper; regular-expression dispatch remains there. Values are limited to one million UTF-16 units/results and a 32 MiB input transport.

The count is **8 new APIs**: `String.localeCompare`, `String.toLocaleLowerCase`, `String.toLocaleUpperCase`, global `escape`, `unescape`, `isXMLName`, and `flash.utils.escapeMultiByte`/`unescapeMultiByte`. The two locale case names reuse the same case kernels rather than adding two algorithms.

**19 existing API paths move to Rust**: `String.charAt`, `charCodeAt`, `concat`, `fromCharCode`, `indexOf`, `lastIndexOf`, `slice`, `split` (literal delimiter), `substr`, `substring`, `toLowerCase`, `toUpperCase`, `toString`, `valueOf`, `replace` (literal pattern), and four URI globals. RegExp paths of `split`/`replace` are not claimed as migrated. No constructor, property, constant or language syntax is added by this family.

`examples/runtime-strings.nflash` contains one ordinary document class, 31 grouped checks over all 27 counted APIs, a combined text pipeline, callback/UTF-16/error checks and a rerun button. The existing two dialect String fixtures are extended without adding execution-fixture entries. One grouped core test covers the family. Actual test/browser results belong to the coordinator's hour report; source inventory alone is not execution evidence.

Deliberate partial boundaries remain: primitive strings, no boxed AS2 values or method extraction/prototype mutation, existing fixed-arity diagnostics, SWF11+ locale comparison rather than OS collation, no full AVM conversion machinery, and the existing regex backend. Existing documented negative `substr` counts, null `split` limits and replacement conversion order remain stable rather than changing silently to every edge of the inspected Ruffle revision. Historical casing changes modern JavaScript Unicode expansion to Flash's single-code-unit maps. URI malformed sequences reject; multibyte APIs deliberately follow their separate lossy/NUL-terminated profile.
