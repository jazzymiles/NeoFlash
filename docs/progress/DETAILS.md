Dockable panels share a four-sided configurable dock grid with resizable areas/groups, ordered tabs, native floating windows and Window ▸ Hide panels (F4). File ▸ Open recent, Close and Revert manage recent and saved documents; Revert also reloads imported FLA/XFL/SWF sources and retains unsaved edits if reload fails, and Control ▸ Enable simple buttons (⌥⌘B) previews Button Up/Over/Down states and press/release feedback live on the authoring Stage. Grid settings offer Dynamic (default: page-aware colour/opacity and adaptive display density) and Static (fixed manual colour/spacing), retaining the configured snapping step and saved manual colour. New/Open insert tabs after the active document; opening an already open native or imported source activates its tab without reloading. Document tabs, the Window list and keyboard cycling retain independent selection, playhead, drafts, Undo and recovery. Close others, Close all and Quit ask for dirty documents in tab order; Cancel or failed Save stops on the prompted tab and preserves deferred discard decisions. Closing the last tab shows New document/Open and disables document commands. Named workspace Save/Replace/Update/Rename/Delete/Reset stores complete dock and floating-window layouts independently of documents and global tool preferences. The window notification host stacks at most three notices above the canvas or status bar, delays them during modals, coalesces repeats, pauses expiry on hover and retains messages in Output; drawing refusals and Save/internal Reload errors are connected. Customize tools edits global tool groups with draft Add/Remove/reorder, Restore default and OK/Cancel.

Output history belongs to each session and is not a persistent disk log; broader operation-specific notification routing is not complete. VoiceOver/IME and mixed-DPI monitors need broader platform acceptance. Dynamic grid contrast follows the page background rather than each artwork pixel. Static preserves manual colour/opacity and hides only an axis whose fixed spacing is below one screen point. Commands/.nfsl execution remains undefined. Brush/Pencil headers use the existing shared TypeHeader until its approved compact variant is supplied; unsupported brush and stroke options remain disabled.

### Library and nested editing

`editor-symbols` · **Partial**

- Working: Convert to Symbol with name, type, folder and registration
- Working: Create/edit nested symbols and double-click empty canvas to return directly to Stage
- Partial: Edit a symbol in place with its transformed parent context dimmed
- Working: Library first-frame preview
- Working: Library folders, search and sorting
- Working: Export identifiers and class linkage
- Working: Button Up/Over/Down/Hit states
- Working: Change symbol type in Library Properties
- Working: Duplicate and delete Library symbols with placement cleanup
- Working: Swap selected stage instances to another Library symbol
- Partial: 9-slice scaling engine; author-facing guide controls pending
- Partial: Portable shared-library linkage and synchronization API; author-facing controls pending
- Working: Drag-and-drop organization of Library folders

**Scope:** Reusable instances and nested editing preserve authored identity and scripts. Edit in place resolves one exact visible placement, composes its invertible affine transform through nested levels, dims the frozen parent context and inverse-maps rendering, picking, selection, transforms, vector tools, drops, snapping and motion overlays; clean isolated definition editing remains a separate route. The session restores each level's playhead, active layer, selection, zoom/pan, ruler zero, frame range and Timeline focus, including paused independent-clip frames. A double-click on genuinely empty canvas with no active draft/gesture exits directly to the root Stage without changing the sticky tool, while breadcrumbs retain level-by-level navigation. Convert to Symbol offers aligned name/type/folder, nine-point registration and export identifier/existing-class fields. The Library shows a real first-frame preview, persistent folders, inline and drag-and-drop folder/symbol organization (`drag_drop_symbol_to_folder`, `drag_drop_folder_to_folder`), search by name/path/linkage/class, Name/Type/Linkage sorting and visible linkage, plus Select unused items, Delete unused items, bulk folder moves and bulk symbol-type changes in one Undo step. Duplicate symbol clones non-scene symbols with fresh IDs and cleared linkage (including Stage context-menu `Duplicate symbol…` on a selected instance); Delete symbol removes the symbol and cleans up any placed instances across timelines in one Undo step; Swap symbol in the Library, Stage context-menu `Swap symbol…` or holding ⌥ (Alt) while dragging a symbol from the Library onto the Stage or a Timeline layer row/frame span replaces the symbol on the selected stage instance or active/hovered layer across its keyframes while preserving transform, name, scripts, filters, blend mode and compatible playback. Symbols also support 9-slice scaling grids (`Scale9Mapping`, keeping the 4 corner regions unstretched while scaling edge and centre regions inversely to the instance's `scale_x`/`scale_y`) and portable Shared Library linkage (`SharedLibraryLinkage` in `library/shared_libraries.json`, `set_symbol_shared_library`, `sync_shared_library`). Folder paths survive symbol clipboard transfers; conflicts reject before mutation. Empty symbol creation opens nested editing. Buttons expose Up/Over/Down/Hit, instance actions and authored/export-linked SimpleButton typing. Library Properties changes kind across references while preserving keys/scripts and refusing incompatible class linkage.

**Limitations:** Edit in place refuses singular/non-finite transforms and non-affine 9-slice scaling instead of mutating geometry in the wrong coordinate space. Local guides and grid work for axis-preserving and quarter-turn mappings. The ruler uses local values only when both mapped axes increase screen-right/down and otherwise falls back to screen values; signed/reflected labels, arbitrary oblique/skewed chrome and the corresponding affine Brush cursor await the locked NF2 contract in R-063. Properties Swap… picker and dedicated ⌥-drag replacement badges wait for NF2 requests R-012 and R-041. ### Work protection and recovery

`platform-recovery` · **Partial**

- Working: Save/Discard/Cancel with work preserved on cancellation or failure
- Working: Autosave
- Working: Crash recovery
- Partial: Detect external file changes

**Scope:** Close, Close all and macOS Quit activate dirty documents in tab order for Save/Discard/Cancel; earlier discard decisions take effect only after the whole sequence is approved. Cancel and failed Save leave the prompted document active with all earlier work and recovery intact. New/Open/Import create accessible tabs and preserve existing work; opening the same native/imported source activates its current tab. Periodic autosave writes dirty documents atomically to `<app_support>/Recovery` every configured N minutes, cleans recovery on save/discard/normal quit and offers Restore/Discard at launch. Each restored copy opens independently; a path conflict creates an unnamed durable copy, and unanswered candidates survive Quit. Failed loading and cancelled pickers preserve existing documents; failed save formatting rolls back and successful formatting is one Undo step. A periodic timestamp check records external changes internally; File → Revert is the available explicit user reload path.

**Limitations:** External file-change detection has an internal validated reload path; broader native change-notification workflow acceptance remains pending. File → Revert remains the explicit user reload command. Document tab sets are not restored on relaunch. The detected-change flag is not connected to a user notification or reload prompt, so external-change detection is only partial as a user-visible function.
