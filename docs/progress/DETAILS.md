## ActionScript 2

Tracked families of language features and Flash APIs. The completed share of this registry is not a percentage of Flash Player compatibility.

### Source diagnostics

`as2-diagnostics` · **Implemented**

**Scope:** Parse errors and unsupported frontend constructs report the language, line and column; compilation errors block export.

**Limitations:** This guarantees compiler diagnostics, not verification of every Flash API semantic.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/src/lib.rs](../../crates/neoflash-script/src/lib.rs), [crates/neoflash-export/src/lib.rs](../../crates/neoflash-export/src/lib.rs)

### Literals

`as2-literals` · **Partial**

**Scope:** Decimal, hexadecimal and exponent numbers; strings; Boolean, null, undefined, NaN and Infinity; arrays without holes and object literals.

**Limitations:** The full set of literals and historical Flash rules is not implemented; legacy numbers with leading zeroes are rejected.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Variables and scope

`as2-variables` · **Partial**

**Scope:** var, multiple declarations, handler-owner fields, and hoisting of local var declarations and parameters.

**Limitations:** Handler fields differ from classes and the full Flash scope chain; top-level declarations follow documented reinitialization rules.

**Evidence:** [crates/neoflash-script/src/actionscript/scope.rs](../../crates/neoflash-script/src/actionscript/scope.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Arithmetic, logic and assignments

`as2-operators` · **Partial**

**Scope:** Basic arithmetic, comparisons, short-circuit evaluation, bitwise operations, ++/-- and compound assignments.

**Limitations:** Some operations use JavaScript coercion; this is not complete AVM semantics across all Flash Player versions.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### If/else branches

`as2-branches` · **Implemented**

**Scope:** Parsing and execution of if/else, blocks and the conditional expression ?:, selecting one branch.

**Limitations:** This covers control flow in the supported frontend; conversion of arbitrary Flash objects remains part of unfinished type compatibility.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs)

### Classic loops and jumps

`as2-loops` · **Implemented**

**Scope:** while, do/while, three-part for, and nested break/continue with jump-target validation.

**Limitations:** for..in property enumeration and full compatibility of condition coercion are tracked separately.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/src/actionscript/control_tests.rs](../../crates/neoflash-script/src/actionscript/control_tests.rs), [crates/neoflash-script/tests/control-flow-fixtures.mjs](../../crates/neoflash-script/tests/control-flow-fixtures.mjs)

### Switch and fallthrough

`as2-switch` · **Implemented**

**Scope:** Single evaluation of the subject, sequential case matching, default, fallthrough and break.

**Limitations:** The supported contract uses strict comparison; compatibility across Flash Player versions is not certified.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/control-flow-fixtures.mjs](../../crates/neoflash-script/tests/control-flow-fixtures.mjs)

### Function declarations and calls

`as2-functions` · **Partial**

**Scope:** Function declarations and expressions, recursion, mutual recursion, return, callbacks and immediately invoked function expressions.

**Limitations:** Declarations must be directly inside a function or handler body; general dynamic method lookup and cross-script symbol resolution are absent.

**Evidence:** [crates/neoflash-script/src/actionscript/scope.rs](../../crates/neoflash-script/src/actionscript/scope.rs), [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs)

### Closures and variable capture

`as2-closures` · **Partial**

**Scope:** Lexical local variables, shadowing, closures retained after return, and capture of the handler owner.

**Limitations:** The complete Flash receiver, global-object and scope-chain models are not implemented.

**Evidence:** [crates/neoflash-script/src/actionscript/scope.rs](../../crates/neoflash-script/src/actionscript/scope.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [crates/neoflash-script/tests/host-integration.mjs](../../crates/neoflash-script/tests/host-integration.mjs)

### Function parameters and returns

`as2-parameters` · **Partial**

**Scope:** Positional parameters; AS2 annotations are erased; missing and extra arguments follow JavaScript behavior.

**Limitations:** Default/rest parameters, arguments and general Function.call/apply are absent; full compatibility of types and invocation errors is unproven.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### this and method binding

`as2-receiver` · **Partial**

**Scope:** this refers to the frame/object handler owner; owner-field names are available inside functions.

**Limitations:** Explicit this in AS2 functions, nested declarations and function expressions is rejected; general receiver behavior is not implemented.

**Evidence:** [crates/neoflash-script/src/actionscript/scope.rs](../../crates/neoflash-script/src/actionscript/scope.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [crates/neoflash-script/tests/host-integration.mjs](../../crates/neoflash-script/tests/host-integration.mjs)

### Annotations and type system

`as2-types` · **Partial**

**Scope:** Selected Number/String/Boolean/Function/Error annotations and return-only Void are accepted; annotations are erased.

**Limitations:** There is no complete type checker, user-defined class model or typed instance-slot model; this.field writes and writes from another handler do not enforce the declared type.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Throw, catch and finally

`as2-exceptions` · **Partial**

**Scope:** Explicit throw preserving the payload, untyped catch and catch(Error), finally and rethrow.

**Limitations:** AS2 catch does not intercept native JavaScript/host errors; catch bindings and variable capture have restrictions.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/src/actionscript/exceptions.js](../../crates/neoflash-script/src/actionscript/exceptions.js), [crates/neoflash-script/tests/control-flow-fixtures.mjs](../../crates/neoflash-script/tests/control-flow-fixtures.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Error objects

`as2-errors` · **Partial**

**Scope:** A limited new Error facade, message and toString.

**Limitations:** General class construction, getStackTrace, complete prototype semantics and all Flash error codes are absent.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/src/actionscript/exceptions.js](../../crates/neoflash-script/src/actionscript/exceptions.js), [crates/neoflash-script/tests/control-flow-fixtures.mjs](../../crates/neoflash-script/tests/control-flow-fixtures.mjs)

### Classes, inheritance and interfaces

`as2-classes` · **Planned**

**Scope:** A complete model of class/interface, extends/implements, members, super, getters/setters and general new.

**Limitations:** These constructs are rejected by the frontend; the Error facade does not implement arbitrary classes.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### Imports and project linking

`as2-imports` · **Planned**

**Scope:** import, external AS2 classes, symbol linkage and cross-file resolution.

**Limitations:** The current compilation unit is an individual synchronous frame or object handler.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/src/actionscript/scope.rs](../../crates/neoflash-script/src/actionscript/scope.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### Dynamic objects and prototypes

`as2-dynamic-object` · **Partial**

**Scope:** Object literals, custom fields, property/index reads and explicitly defined function members.

**Limitations:** There is no complete Object/prototype/scope-chain model; computed calls, general alias/type inference and some dynamic methods are rejected.

**Evidence:** [crates/neoflash-script/src/actionscript/scope.rs](../../crates/neoflash-script/src/actionscript/scope.rs), [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Property enumeration and with

`as2-enumeration` · **Planned**

**Scope:** for..in enumeration and correct name lookup inside with.

**Limitations:** These are unsupported; a classic three-part for loop does not implement property enumeration.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Additional language operators

`as2-special-operators` · **Planned**

**Scope:** instanceof, in, delete, unary void and general new.

**Limitations:** These are rejected with diagnostics; the separate new Error facade does not complete this capability.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Primitives and global conversions

`as2-primitive-globals` · **Partial**

**Scope:** Number, String, Boolean, parseInt, parseFloat, isNaN and isFinite are available through JavaScript.

**Limitations:** Flash-specific and version-specific rules, boxed values and the complete standard library are not implemented.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Math

`as2-math` · **Partial**

**Scope:** A closed list of numeric Math methods, including trigonometry, abs, min/max, pow, random and round.

**Limitations:** Execution is delegated to JavaScript; the full contract and numerical equivalence with Flash are not certified.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Array, String and Number methods

`as2-collections` · **Partial**

**Scope:** Selected push/pop/shift/unshift/join/slice/indexOf/substring/charAt/charCodeAt/toString/toFixed/split/concat/reverse methods.

**Limitations:** The list is limited and uses JavaScript behavior, with possible differences in ranges, coercion and errors.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Trace through the browser host

`as2-trace` · **Implemented**

**Scope:** trace from handlers and nested functions runs through the host, updating the console and player status line.

**Limitations:** This implements the observable NeoFlash output channel; complete formatting of all Flash types is not claimed.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [web/runtime.js](../../web/runtime.js), [crates/neoflash-script/tests/host-integration.mjs](../../crates/neoflash-script/tests/host-integration.mjs)

### MovieClip and timelines

`as2-timeline` · **Partial**

**Scope:** play/stop, gotoAndPlay/gotoAndStop, nextFrame/prevFrame, current/total frames, named children and independent nested clocks.

**Limitations:** This is a limited MovieClip facade; complete construction/re-entry, scenes, dynamic display lists and the Flash lifecycle are not implemented.

**Evidence:** [web/runtime.js](../../web/runtime.js), [crates/neoflash-core/tests/core.rs](../../crates/neoflash-core/tests/core.rs), [web/tests/runtime.test.cjs](../../web/tests/runtime.test.cjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Display properties

`as2-display` · **Partial**

**Scope:** Position, rotation, alpha and scale; AS2 aliases _x/_y/_rotation/_alpha/_xscale/_yscale, root/parent.

**Limitations:** The complete DisplayObject API, visible, width/height, mask and filters are absent; arbitrary custom fields do not prove a change to the rendered image.

**Evidence:** [web/runtime.js](../../web/runtime.js), [crates/neoflash-core/tests/core.rs](../../crates/neoflash-core/tests/core.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Events and handlers

`as2-events` · **Partial**

**Scope:** Authored frame scripts and load/click/enter_frame object events; target-lifetime checks and a limit on recursive dispatch.

**Limitations:** The complete Flash event model, keyboard/mouse APIs, button states and compatible ordering of all lifecycle events are absent.

**Evidence:** [web/runtime.js](../../web/runtime.js), [crates/neoflash-core/tests/core.rs](../../crates/neoflash-core/tests/core.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Programmatic drawing

`as2-graphics-api` · **Planned**

**Scope:** MovieClip drawing APIs, bitmap fills and programmatic Flash graphics.

**Limitations:** Authored vector shapes and their Canvas rendering do not provide a Graphics API callable from ActionScript.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md), [web/runtime.js](../../web/runtime.js)

### TextField and text APIs

`as2-text-api` · **Planned**

**Scope:** Dynamic and input text, formatting, measurement, selection and programmatic TextField control.

**Limitations:** Static text in the document model does not implement Flash TextField; a custom field named text does not change the rendered string.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md), [web/runtime.js](../../web/runtime.js)

### Audio, video and resource loading

`as2-media-api` · **Planned**

**Scope:** Flash media APIs, loading of images, audio and video, playback control and synchronization.

**Limitations:** The authoring/runtime model does not yet provide the corresponding ActionScript APIs.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### Networking, storage and external communication

`as2-network-api` · **Planned**

**Scope:** Flash networking/loaders, SharedObject and explicitly defined browser bridges.

**Limitations:** JavaScript access to the browser does not imply support for equivalent ActionScript APIs.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### Components and platform libraries

`as2-components` · **Planned**

**Scope:** AS2 UI/component libraries and related Flash platform APIs.

**Limitations:** These libraries are not implemented; porting platform APIs requires an explicit supported/adapted/unavailable contract.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### Complete virtual-machine semantics

`as2-vm-conformance` · **Planned**

**Scope:** AVM1 compatibility, including Flash Player versions, coercion, scope chains and runtime errors.

**Limitations:** The current frontend emits JavaScript; internal regression tests are not Flash Player conformance certification.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### Debugger and source maps

`as2-debugger` · **Planned**

**Scope:** ActionScript debugging with original source lines, breakpoints and state inspection.

**Limitations:** Compile/publish diagnostics exist; a complete source debugger is absent.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### Source on / onClipEvent wrappers

`as2-event-wrappers` · **Planned**

**Scope:** Parsing legacy object-script wrappers and compatible AS2 event registration.

**Limitations:** The editor event selector accepts only a handler body; source wrappers are unsupported.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### XML

`as2-xml` · **Planned**

**Scope:** AS2 XML/XMLNode and their parsing, traversal and networking contracts.

**Limitations:** The XML API is absent; XML parsing in the XFL importer does not execute AS2 XML.

**Evidence:** [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

`imports-script-retention` · **Partial**

**Scope:** Supported XFL preserves frame ActionScript source and an unambiguously identified AS2/AS3 language.

**Limitations:** Document class/linkage and external script configuration block import; retaining source does not prove execution.

**Evidence:** [crates/neoflash-import/src/xfl.rs](../../crates/neoflash-import/src/xfl.rs), [docs/IMPORTS.md](../../docs/IMPORTS.md)

### Container reading and limits

`imports-container-safety` · **Implemented**

**Scope:** Format detection, bounded ZIP/CFB readers, path/size/integrity checks and explicit refusal without overwriting the source.

**Limitations:** Respecting container boundaries does not establish support for its contents.

**Evidence:** [crates/neoflash-import/src/source.rs](../../crates/neoflash-import/src/source.rs), [crates/neoflash-import/src/legacy.rs](../../crates/neoflash-import/src/legacy.rs), [crates/neoflash-import/tests/binary.rs](../../crates/neoflash-import/tests/binary.rs), [crates/neoflash-import/tests/import.rs](../../crates/neoflash-import/tests/import.rs)

### Binary FLA structure

`imports-binary-structure` · **Partial**

**Scope:** CFB/MFC inventory, bounded Contents preservation, an identity graph and typed timeline records with exact unread boundaries.

**Limitations:** Later Contents suffixes, many object classes, media and historical actions are not fully readable yet.

**Evidence:** [crates/neoflash-import/src/legacy/contents.rs](../../crates/neoflash-import/src/legacy/contents.rs), [crates/neoflash-import/src/legacy/timeline.rs](../../crates/neoflash-import/src/legacy/timeline.rs), [crates/neoflash-import/tests/binary_timeline.rs](../../crates/neoflash-import/tests/binary_timeline.rs), [docs/IMPORTS.md](../../docs/IMPORTS.md)

### Binary FLA geometry

`imports-binary-geometry` · **Partial**

**Scope:** Preserve bounded shape/style/edge records and original bytes; a strict adapter maps some Flash 3 solid contours to core Path.

**Limitations:** Supported revisions, paints and topology are limited; successful contour conversion does not create an editable document.

**Evidence:** [crates/neoflash-import/src/legacy/geometry.rs](../../crates/neoflash-import/src/legacy/geometry.rs), [crates/neoflash-import/src/legacy/contours.rs](../../crates/neoflash-import/src/legacy/contours.rs), [crates/neoflash-import/tests/binary_contours.rs](../../crates/neoflash-import/tests/binary_contours.rs)

### Binary FLA to editable document

`imports-binary-document` · **Planned**

**Scope:** Complete document conversion with layer order, placement identity, text, linkage, media, metadata and supported actions.

**Limitations:** All binary documents in the current corpus remain can_import=false; structural reading does not count as document import.

**Evidence:** [docs/IMPORTS.md](../../docs/IMPORTS.md), [docs/BACKLOG.md](../../docs/BACKLOG.md)

### SWF inspection

`imports-swf-inspection` · **Partial**

**Scope:** Recognizes FWS/CWS/ZWS signatures and header/version fields.

**Limitations:** Decompression, tag parsing, AVM1/AVM2 execution and source reconstruction are absent.

**Evidence:** [crates/neoflash-import/src/lib.rs](../../crates/neoflash-import/src/lib.rs), [crates/neoflash-import/tests/import.rs](../../crates/neoflash-import/tests/import.rs), [docs/IMPORTS.md](../../docs/IMPORTS.md)

### SWF playback and import

`imports-swf-playback` · **Planned**

**Scope:** A separate architecture for legacy playback and structured import; evaluation of Ruffle integration.

**Limitations:** Ruffle is not integrated; SWF playback alone does not recover layers, source scripts or tween intent.

**Evidence:** [docs/IMPORTS.md](../../docs/IMPORTS.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### SWC and external AS libraries

`imports-external-libraries` · **Planned**

**Scope:** Dependency models, linkage, versions and the source/bytecode boundary for external libraries.

**Limitations:** SWC import and a working linker are absent.

**Evidence:** [docs/IMPORTS.md](../../docs/IMPORTS.md), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Compatibility corpus and fidelity

`imports-corpus` · **Partial**

**Scope:** Original synthetic fixtures cover containers, Contents, timelines and geometry; a local private corpus supplies aggregates and refusal reasons.

**Limitations:** Complete reproducible per-file visual/behavioral comparisons across Flash generations are missing. Private artwork is not published.

**Evidence:** [crates/neoflash-import/tests/binary_geometry.rs](../../crates/neoflash-import/tests/binary_geometry.rs), [crates/neoflash-import/tests/binary_contents.rs](../../crates/neoflash-import/tests/binary_contents.rs), [docs/IMPORTS.md](../../docs/IMPORTS.md), [docs/BACKLOG.md](../../docs/BACKLOG.md)

## Platform and quality

Project format, macOS, verification, accessibility and application delivery.

### Independent project format

`platform-document-model` · **Implemented**

**Scope:** Versioned JSON stores symbols, instances, frames and scripts with stable IDs; validation checks references, cycles and bounds.

**Limitations:** Future version migrations and external resources require separate format extensions.

**Evidence:** [crates/neoflash-core/src/model.rs](../../crates/neoflash-core/src/model.rs), [crates/neoflash-core/src/validation.rs](../../crates/neoflash-core/src/validation.rs), [crates/neoflash-core/tests/core.rs](../../crates/neoflash-core/tests/core.rs)

### Save and open projects

`platform-save-open` · **Implemented**

**Scope:** The editor saves and opens .nflash through serialization and validation, without tying the document to absolute paths.

**Limitations:** Autosave, recovery and multiple documents are tracked separately.

**Evidence:** [crates/neoflash-editor/src/app.rs](../../crates/neoflash-editor/src/app.rs), [crates/neoflash-core/src/lib.rs](../../crates/neoflash-core/src/lib.rs), [README.md](../../README.md)

### Undo/Redo for authoring operations

`platform-undo` · **Implemented**

**Scope:** Change history with one Undo for a completed gesture; a new edit invalidates the redo branch.

**Limitations:** Resource-aware history for large projects remains to be implemented.

**Evidence:** [crates/neoflash-core/src/history.rs](../../crates/neoflash-core/src/history.rs), [crates/neoflash-core/tests/core.rs](../../crates/neoflash-core/tests/core.rs), [crates/neoflash-editor/src/selection_tests.rs](../../crates/neoflash-editor/src/selection_tests.rs)

### Work protection and recovery

`platform-recovery` · **Partial**

**Scope:** Unsaved projects offer Save/Discard/Cancel before New/Open/Import/Close.

**Limitations:** Autosave/crash recovery, file-change detection and multiple documents are not implemented yet.

**Evidence:** [crates/neoflash-editor/src/app.rs](../../crates/neoflash-editor/src/app.rs), [docs/BACKLOG.md](../../docs/BACKLOG.md), [docs/ROADMAP.md](../../docs/ROADMAP.md)

### macOS integration

`platform-native-macos` · **Partial**

**Scope:** Rust/egui application, core shortcuts, system fonts and a local .app for macOS 15+.

**Limitations:** Native menus/document integration, IME, the accessibility tree and trackpad conventions need further work.

**Evidence:** [crates/neoflash-editor/src/main.rs](../../crates/neoflash-editor/src/main.rs), [crates/neoflash-editor/src/fonts.rs](../../crates/neoflash-editor/src/fonts.rs), [scripts/package-macos.sh](../../scripts/package-macos.sh), [docs/BACKLOG.md](../../docs/BACKLOG.md)

### Automated checks

`platform-verification` · **Implemented**

**Scope:** check.sh runs formatting/lint, Rust tests, the WASM build and tests with actual WASM; CI is defined in the repository.

**Limitations:** This records the existence of the test harness, not a new run result or a complete Flash conformance suite.

**Evidence:** [scripts/check.sh](../../scripts/check.sh), [.github/workflows/check.yml](../../.github/workflows/check.yml), [docs/VERIFICATION.md](../../docs/VERIFICATION.md)

### Scaling to large projects

`platform-performance` · **Partial**

**Scope:** Validation/work budgets, expansion limits and cached browser path geometry exist.

**Limitations:** Complete timeline virtualization, resource-aware undo and published performance budgets are missing.

**Evidence:** [crates/neoflash-core/src/validation.rs](../../crates/neoflash-core/src/validation.rs), [web/tests/path-cache.test.cjs](../../web/tests/path-cache.test.cjs), [docs/BACKLOG.md](../../docs/BACKLOG.md)

### Signed releases and platform matrix

`platform-release` · **Partial**

**Scope:** Local .app packaging with ad-hoc signing; Apple Silicon is documented as locally tested.

**Limitations:** A notarized distribution release, verified Intel build, complete browser matrix and updater policy are absent.

**Evidence:** [scripts/package-macos.sh](../../scripts/package-macos.sh), [README.md](../../README.md), [docs/BACKLOG.md](../../docs/BACKLOG.md)

### Extensions and localization

`platform-extensions` · **Planned**

**Scope:** Public extension API, interface localization and stable product extension contracts.

**Limitations:** The API and extension policy have not been defined yet.

**Evidence:** [docs/PRODUCT.md](../../docs/PRODUCT.md), [docs/BACKLOG.md](../../docs/BACKLOG.md)

### Editor accessibility and overall verification

`platform-accessibility` · **Partial**

**Scope:** Authored Button/Image metadata and individual browser keyboard/focus checks exist.

**Limitations:** The native accessibility tree, VoiceOver and end-to-end accessibility verification for authors and visitors are still needed.

**Evidence:** [crates/neoflash-editor/src/accessibility.rs](../../crates/neoflash-editor/src/accessibility.rs), [docs/WEB.md](../../docs/WEB.md), [docs/VERIFICATION.md](../../docs/VERIFICATION.md), [docs/BACKLOG.md](../../docs/BACKLOG.md)
