### Primitives and global conversions

`as2-primitive-globals` · **Partial**

**Scope:** Number, Boolean, parseFloat, isNaN and isFinite retain JavaScript-backed conversions. String now uses the bounded primitive family facade; parseInt retains its separate pinned AS2 profile and earlier HTML5 acceptance. Bare getTimer() reads signed 32-bit elapsed milliseconds from the publication session clock. The bounded Rust reuse experiment adds escape/unescape and the legacy chr/ord/length/substring plus mb variants; eight legacy names share four kernels. The existing AS2 random global now calculates its range in Rust; it is included once in the 19 migrated Math/global paths. Callback setInterval/setTimeout and clearInterval/clearTimeout now share the Rust timer registry and publication lifecycle. The bounded AS2-only delivery and exact declaration profiles are recorded in docs/AS2-LEGACY-BATCH.md.

## Import and file compatibility

Structural inspection and conversion to an editable project are tracked separately.

### XFL and ZIP-FLA to project

`imports-xfl` · **Partial**

**Scope:** One scene, library, held keys, labels, nested instances, TRS/alpha, primitives, simple static text and a bounded subset of convex straight DOMShape geometry with solid fills and round strokes. Selected-profile InvisibleLayer policy and blank-gap placement IDs are preserved; ambiguous adjacent continuity and unsupported excluded-layer behavior produce diagnostics.

**Limitations:** One unchanged real CS6 FLA has browser acceptance. General DOMShape, masks, media, rich text and skew are incomplete. Adjacent same-symbol continuity and excluded scripts/labels/extended duration are explicitly refused.

**Evidence:** [crates/neoflash-import/src/xfl.rs](../../crates/neoflash-import/src/xfl.rs), [crates/neoflash-import/src/xfl/shape.rs](../../crates/neoflash-import/src/xfl/shape.rs), [crates/neoflash-import/tests/public_fla.rs](../../crates/neoflash-import/tests/public_fla.rs), [crates/neoflash-import/tests/xfl_semantic_guards.rs](../../crates/neoflash-import/tests/xfl_semantic_guards.rs), [docs/IMPORTS.md](../../docs/IMPORTS.md), [crates/neoflash-import/tests/xfl_publish_identity.rs](../../crates/neoflash-import/tests/xfl_publish_identity.rs), [docs/VERIFICATION.md](../../docs/VERIFICATION.md)

## Platform and quality

Project format, macOS, verification, accessibility and application delivery.

### Independent project format

`platform-document-model` · **Implemented**

**Scope:** Versioned JSON stores stable symbols/placements/frames/scripts; version 2 adds logical project source units and document/symbol linkage with path, size and reference validation. Existing version-1 projects remain supported. Version 3 adds portable resource bytes, normalized logical paths/types, strict base64/size validation and shared immutable storage across native snapshots; versions 1 and 2 remain readable. Authored Bitmap elements reference portable PNG/JPEG resource IDs with validated intrinsic dimensions; mutable runtime pixels stay outside the document. TextBox stores explicit layout dimensions and uniform formatting; legacy Text remains readable without conversion, and runtime insertion defaults stay outside authored state.

**Limitations:** Additional media consumers, embedded font layout and broader asset dependency authoring remain separate work. Independent c39a29e acceptance (RESOURCES-HTML5-20261027T0323Z) covers the precise embedded/HTTP and pending-request observations in VERIFICATION.md; native resource authoring and full network semantics remain unverified. Independent 1bd0e3c evidence (BITMAP-HTML5-20261027T0345Z) is restricted to the PNG/shared pixel, AS2 attachment, disposal and Restart observations in VERIFICATION.md. JPEG, rasterization options, alpha hits and native image authoring do not inherit that pass.

**Evidence:** [crates/neoflash-core/src/model.rs](../../crates/neoflash-core/src/model.rs), [crates/neoflash-core/src/validation.rs](../../crates/neoflash-core/src/validation.rs), [crates/neoflash-core/tests/core.rs](../../crates/neoflash-core/tests/core.rs), [crates/neoflash-core/tests/program.rs](../../crates/neoflash-core/tests/program.rs), [crates/neoflash-core/src/resources.rs](../../crates/neoflash-core/src/resources.rs), [crates/neoflash-editor/src/resources.rs](../../crates/neoflash-editor/src/resources.rs), [docs/decisions/0013-portable-resources-and-loading.md](../../docs/decisions/0013-portable-resources-and-loading.md), [docs/VERIFICATION.md](../../docs/VERIFICATION.md), [crates/neoflash-core/src/resource_image.rs](../../crates/neoflash-core/src/resource_image.rs), [docs/decisions/0014-bitmap-pixels.md](../../docs/decisions/0014-bitmap-pixels.md), [docs/progress/actionscript-audit.json](../../docs/progress/actionscript-audit.json), [crates/neoflash-core/src/text.rs](../../crates/neoflash-core/src/text.rs), [docs/decisions/0015-text-fields-and-layout.md](../../docs/decisions/0015-text-fields-and-layout.md)
