### Source diagnostics

`as2-diagnostics` · **Implemented**

**Scope:** Parse errors and unsupported frontend constructs report the language, line and column; compilation errors block export.

**Limitations:** This guarantees compiler diagnostics, not verification of every Flash API semantic.

### Literals

`as2-literals` · **Partial**

**Scope:** Decimal, hexadecimal and exponent numbers; strings; Boolean, null, undefined, NaN and Infinity; arrays without holes and object literals.

**Limitations:** The full set of literals and historical Flash rules is not implemented; legacy numbers with leading zeroes are rejected.

**Evidence:** [crates/neoflash-script/src/actionscript.rs](../../crates/neoflash-script/src/actionscript.rs), [crates/neoflash-script/tests/execute.mjs](../../crates/neoflash-script/tests/execute.mjs), [docs/COMPATIBILITY.md](../../docs/COMPATIBILITY.md)

### Variables and scope

`as2-variables` · **Partial**

**Scope:** var, multiple declarations, handler-owner fields, and hoisting of local var declarations and parameters.

**Limitations:** Handler fields differ from classes and the full Flash scope chain; top-level declarations follow documented reinitialization rules.

`as2-operators` · **Partial**

### Primitives and global conversions

`as2-primitive-globals` · **Partial**

**Scope:** Number, Boolean, parseFloat, isNaN and isFinite retain JavaScript-backed conversions. ### Math

`as2-math` · **Partial**

## Import and file compatibility

Structural inspection and conversion to an editable project are tracked separately.

### XFL and ZIP-FLA to project

`imports-xfl` · **Partial**

**Scope:** One scene, library, held keys, labels, nested instances, TRS/alpha, primitives, simple static text and a bounded subset of convex straight DOMShape geometry with solid fills and round strokes. Selected-profile InvisibleLayer policy and blank-gap placement IDs are preserved; ambiguous adjacent continuity and unsupported excluded-layer behavior produce diagnostics.

**Limitations:** One unchanged real CS6 FLA has browser acceptance. General DOMShape, masks, media, rich text and skew are incomplete. Adjacent same-symbol continuity and excluded scripts/labels/extended duration are explicitly refused.

**Evidence:** [crates/neoflash-import/src/xfl.rs](../../crates/neoflash-import/src/xfl.rs), [crates/neoflash-import/src/xfl/shape.rs](../../crates/neoflash-import/src/xfl/shape.rs), [crates/neoflash-import/tests/public_fla.rs](../../crates/neoflash-import/tests/public_fla.rs), [crates/neoflash-import/tests/xfl_semantic_guards.rs](../../crates/neoflash-import/tests/xfl_semantic_guards.rs), [docs/IMPORTS.md](../../docs/IMPORTS.md), [crates/neoflash-import/tests/xfl_publish_identity.rs](../../crates/neoflash-import/tests/xfl_publish_identity.rs), [docs/VERIFICATION.md](../../docs/VERIFICATION.md)

### Imported source preservation

`imports-script-retention` · **Partial**

**Scope:** Supported XFL preserves frame source and language, including text/CDATA fragments; nine original AS2 scripts from one CS6 FLA were checked against an exact 17-line HTML5 trace.

**Limitations:** Document class/linkage and active external script configuration block import; retaining arbitrary source does not prove execution.

**Evidence:** [crates/neoflash-import/src/xfl.rs](../../crates/neoflash-import/src/xfl.rs), [crates/neoflash-import/tests/xfl_semantic_guards.rs](../../crates/neoflash-import/tests/xfl_semantic_guards.rs), [web/tests/real-fla-frame-labels.test.cjs](../../web/tests/real-fla-frame-labels.test.cjs), [docs/IMPORTS.md](../../docs/IMPORTS.md)

`imports-container-safety` · **Implemented**

`imports-binary-structure` · **Partial**

## Platform and quality

Project format, macOS, verification, accessibility and application delivery.

### Independent project format

`platform-document-model` · **Implemented**

**Scope:** Versioned JSON stores stable symbols/placements/frames/scripts; version 2 adds logical project source units and document/symbol linkage with path, size and reference validation. Existing version-1 projects remain supported.

**Limitations:** Future migrations and external bitmap/font/media resources require further format work; project source text is not a general resource graph.

**Evidence:** [crates/neoflash-core/src/model.rs](../../crates/neoflash-core/src/model.rs), [crates/neoflash-core/src/validation.rs](../../crates/neoflash-core/src/validation.rs), [crates/neoflash-core/tests/core.rs](../../crates/neoflash-core/tests/core.rs), [crates/neoflash-core/tests/program.rs](../../crates/neoflash-core/tests/program.rs)

`platform-save-open` · **Implemented**

**Scope:** The editor saves and opens .nflash through serialization and validation, without tying the document to absolute paths.

`platform-undo` · **Implemented**

`platform-recovery` · **Partial**

`platform-native-macos` · **Partial**
